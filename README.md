# how to work on the game
  To work on it from your browser:\
  Click the green "Code" button\
  Click Create Codespace (if you have issues change your wifi/ethernet/hotspot)\
  Click Yes if it asks you to trust files\
  Click on the extensions button on the left sidebar. Add the "Python" and "ren'py" extension\
  You can pull up the renpy tutorial on the side, the instructions there are compatible w Codespace.

  To work on it from your local machine:\
  Choose your IDE of choice (I prefer VSE)\
  Download git to your computer's terminal\
  You'll need to read some tutorials on how to setup git and connect your computer to the github repository\
  Add extensions for Python and Ren'py.
  
# how to refresh the code!!!
  Do this EVERY time before you start adding code\
  Do a "pull" command before you start working on the code\
    This is how you refresh the code in order to show any recent changes other members have made\
  For Codespace, click on the source control button on the left sidebar. Then click on the 3 dots. The pull button should show up.
  
# how to commit/save changes to the code
  Click on the source control button on the left sidebar (or wherever you go to commit changes)\
  Click on the little arrow on the button that says "commit" it should bring out a little menu\
  Click on "Commit & Push"

# how download the game (for testing)
  Click on the green Code button\
  Click on download zip file\
  Copy the zip file to your ren'py directory\
    To find your ren'py repository:\
      Open Ren'py and click on preferences (in the bottom right corner)\
      The directory should be listed under "Projects Directory"\
  Unzip the file (feel free to now delete the zip file)\
  In Ren'py, click "refresh". The name of the game should now show up for you to click on and play.
